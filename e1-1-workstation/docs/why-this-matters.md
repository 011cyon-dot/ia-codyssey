# 이걸 왜 하나 — AI 과정에서 터미널·Docker·Git 을 먼저 배우는 이유

실습하는 동안에는 "AI 과정인데 왜 폴더 만들고 컨테이너 켜고 끄는 걸 하지?" 싶었다.
끝나고 정리해 보니, AI 를 **쓰는** 쪽이 아니라 **만들고 돌리는** 쪽의 바닥이 이것이었다.

## 솔직히: 모르고 따라 친 것들

실습할 때는 **컨테이너가 뭔지도 모르고** 명령을 따라 쳤다. 출력이 나오니 된 줄 알았지만, 무엇이 됐는지는 몰랐다.
끝나고 하나씩 물어서 이해한 것을 내 말로 적는다.

| 모르고 쓴 말 | 지금 이해한 것 |
|---|---|
| 컨테이너 | 내 컴퓨터 안에 따로 떼어 낸 **작은 컴퓨터**. 안에서 무엇을 깔고 지워도 내 컴퓨터는 그대로다. 다 쓰면 통째로 버린다. **단, 바인드 마운트로 연결한 내 폴더는 예외** — 안에서 지우면 내 컴퓨터에서도 지워진다 |
| 이미지 | 그 작은 컴퓨터를 찍어 내는 **설계도**. `nginx:alpine` 설계도 하나로 web1, web2 두 대를 만들었다 |
| `docker run` | 설계도로 작은 컴퓨터를 **만들고 켜기** |
| `-d` | 켜 놓고 내 터미널은 돌려받기(뒤에서 돌리기) |
| `stop` / `rm` | 끄기 / 버리기. 켜진 걸 바로 버릴 수는 없어서 끄고 버린다 |
| `exec` / `attach` | 작은 컴퓨터에 새 창으로 들어가기 / 원래 창에 붙기. attach 로 들어가 `exit` 하면 컴퓨터가 꺼진다 |
| 포트 `-p 8080:80` | 작은 컴퓨터는 막혀 있어서, 내 컴퓨터 8080번 문과 그 안의 80번 문을 **이어 줘야** 브라우저로 들어간다 |
| 바인드 마운트 | 내 폴더를 작은 컴퓨터 안에 **그대로 연결**. 내 파일을 고치면 안에서도 바로 바뀐다. 반대로 안에서 고치거나 지워도 내 파일이 바뀐다. 읽기만 시키려면 끝에 `:ro` 를 붙인다(`-v "C:/workstation/site:/usr/share/nginx/html:ro"`) |
| 볼륨 | 작은 컴퓨터를 버려도 **남는 보관함** |
| Dockerfile | 설계도(이미지)를 **만드는 순서를 적은 글**. "nginx 를 바탕으로, 내 페이지를 넣어라" 두 줄 |
| WSL2 | 윈도우 안에서 리눅스를 돌리는 장치. Docker 의 작은 컴퓨터들은 리눅스라 이게 필요했다 |

배운 점: **명령이 성공했다 ≠ 내가 이해했다.** 출력 한 줄 한 줄이 무슨 뜻인지 설명할 수 있어야 끝이다. 출력 읽는 법은 [reading-outputs.md](reading-outputs.md) 에 따로 정리했다.

## 오늘 배운 것 → AI 일에서 쓰이는 곳

| 오늘 배운 것 | AI 일에서는 |
|---|---|
| 터미널 | AI 모델 학습·실행은 거의 다 터미널에서 한다. 코딩을 도와주는 AI 도구(Claude Code 등)도 터미널에서 돌아간다 |
| 권한 (`chmod`) | API 키 같은 비밀 파일을 나만 읽게(`600`) 막는다 |
| Docker 이미지·컨테이너 | AI 프로그램은 파이썬 버전·라이브러리·GPU 설정이 조금만 달라도 안 돌아간다. 그래서 통째로 이미지에 담아 어디서든 똑같이 돌린다 |
| Dockerfile | "무엇을 깔고 무엇을 넣을지"를 글로 남겨서, 남이 그대로 다시 만들 수 있다 |
| 포트 매핑 | AI 모델을 웹 서버로 띄워 두고, 앱이 `주소:포트` 로 질문을 보낸다 |
| 바인드 마운트 | 코드를 고치면 컨테이너를 다시 만들지 않고 바로 확인한다 |
| 볼륨 | 모델 파일·데이터(수 GB)를 컨테이너를 지워도 남게 따로 보관한다 |
| Git/GitHub | 코드와 실험 기록을 남긴다. AI 가 짠 코드도 여기서 검토하고, 틀리면 되돌린다 |

## 한 줄로

**"내 컴퓨터에서만 되는" AI 는 쓸 수 없다.** 어느 컴퓨터에서든 똑같이 돌아가게 하는 바탕이 컨테이너·포트·볼륨·Git 이다.

## 내 경우에 대보면

- 내가 쓰는 업무 앱도 내 컴퓨터에서 포트를 열어 떠 있고, 화면은 따로 있다. 오늘 `-p 8080:80` 으로 한 것과 같은 구조다.
- 고친 코드를 GitHub 에 올리면 자동으로 배포된다. 오늘 `git push` 한 것의 다음 단계다.

## 느낀점

처음엔 AI 과정에서 왜 터미널과 Docker 부터 하나 싶었다. 실습 중에는 컨테이너가 뭔지도 모르고 따라 쳤다.
끝나고 하나씩 물어 보니 AI 프로그램도 결국 어느 컴퓨터에서든 똑같이 돌아가야 쓸 수 있고, 그 바탕이 컨테이너·포트·볼륨·Git 이었다.
내가 이미 쓰는 AI 도구들도 이 위에서 돌아간다는 걸 알게 됐다.
